Monica Para, a 25-year-old data analyst in Chicago, shares how she began coding with Codecademy in 2015 learning HTML, CSS, and JavaScript, attended Girls Who Code programs, completed a computer science degree, and eventually shifted from software engineering to data analytics. She emphasizes mastering coding fundamentals rather than relying on AI as a shortcut, and advises approaching learning by identifying problems first rather than focusing solely on programming languages.
